# An example of using an overlayed egui window within a wgpu app

This is, for the most part, taken straight from
[wgpu's tutorial 12](<https://github.com/sotrh/learn-wgpu/tree/master/code/intermediate/tutorial12-camera>),
which introduces nicer camera controls.
I feel overall this makes for a nice starting point for graphics work
with wgpu including nice little devknobs.
